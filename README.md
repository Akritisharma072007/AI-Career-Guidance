AI-Based Career Guidance and Prediction System

Project Overview

The AI-Based Career Guidance and Prediction System is a machine learning application designed to help students explore suitable career options based on their skills, interests, and academic preferences.

Objectives

- Provide personalized career recommendations.
- Help students explore suitable career paths.
- Demonstrate the use of machine learning in career guidance.

Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Random Forest Classifier

Key Features

- Student assessment form
- Skill and interest selection
- Machine learning-based career prediction
- Interactive web interface

Current Progress

- Dataset prepared.
- Machine learning model trained.
- Model integrated with the Streamlit application.
- Basic career prediction tested.

Future Scope

- Expand the training dataset.
- Evaluate model accuracy.
- Improve the user interface.
- Add career descriptions and personalized learning roadmaps.
